## 01 — The Arc

Four acts. Eight scenes. One narrative.

```
Act 1 — Category (Scenes 1–2)
  Scene 01: Curiosity   → Name the category.
  Scene 02: Concern     → Validate the pain.

Act 2 — Framework (Scene 3)
  Scene 03: Understanding → Teach the mental model.

Act 3 — Evidence (Scenes 4–6)
  Scene 04: Relief        → Reveal the platform.
  Scene 05: Confidence    → Capabilities prove the category.
  Scene 06: Trust         → Enterprise-scale proof.

Act 4 — Horizon (Scenes 7–8)
  Scene 07: Inspiration   → Paint the future.
  Scene 08: Action        → Extend the invitation.
```

## 03 — Scene by Scene

### Scene 01 — The Category

**Question:** What is Enterprise Intelligence Infrastructure?
**Emotion:** Curiosity
**Duration:** 0–15% scroll (15s)

| Element | Description |
|---------|-------------|
| **Camera** | Static. Fixed position. The world exists but is not yet revealed. |
| **World** | Dark void. Particles are scattered, random, directionless. Raw data before intelligence. |
| **Motion** | Particles begin to pulse gently. A rhythm emerges. Then particles start flowing inward — assembling into a central core. The core forms slowly, deliberately. |
| **Lighting** | 15% intensity. Neutral. Just enough to see the core forming. |
| **Content** | Text generates from particles: "Enterprise Intelligence Infrastructure." The category name is the first thing the visitor reads. |
| **Sound** | Low ambient hum. A single tone emerges as the core completes. |
| **Interaction** | Mouse movement slightly influences particle flow direction. Subtle. The visitor feels their presence matters. |
| **Exit** | Scroll reaches 15%. The core is complete. |

**What the user learns:** A new category exists. It has a name.

### Scene 02 — The Problem

**Question:** Why does it matter?
**Emotion:** Concern
**Duration:** 15–35% scroll (20s)

| Element | Description |
|---------|-------------|
| **Camera** | Pull Back. The camera slowly widens to reveal the full scope of the problem. |
| **World** | The core fragments. Particles break apart into isolated clusters — silos. Each cluster moves independently, disconnected from the others. |
| **Motion** | Particles disconnect into silos. Each silo pulses with its own rhythm. No communication between them. The fragmentation is visible. |
| **Lighting** | Drops to 5%. Cool blue. The darkest scene. The problem is serious. |
| **Content** | Text dissolves from particles: "Data is everywhere. Intelligence is nowhere." Each word is a separate silo. |

| **Interaction** | Scroll reveals more fragmentation. The further the user scrolls, the more broken the world becomes. |

**What the user learns:** The problem is real, serious, and systemic. Intelligence Fragmentation is the enemy.

## 07 — Transition Rules

### Scene transitions

- Each transition begins when the next scene reaches 40% of viewport
- Transitions overlap by 20% of the scene duration
- Camera position changes only at scene boundaries (never mid-scene)
- Particles persist across scenes (channel configurations change, particles do not reset)
- Lighting blends over 800ms between scenes
- Sound crossfades over 1000ms between scenes

### Page transitions

- Internal page transitions: 600ms, power2.inOut
- Scene transitions: 1500ms, power4.out (scroll-scrubbed)
- No transition on first visit (cold boot)
- Transitions are skipped if `prefers-reduced-motion: reduce`

### Nav transitions

- Nav appears: 400ms, power2.out
- Nav hides: 300ms, power2.in
- Page change via nav: page transition + nav state update

## 08 — Interaction Design

| Scene | Primary Interaction | Secondary |
|-------|-------------------|-----------|
| 01 | Mouse (particle direction) | Scroll entry |
| 02 | Scroll (reveal fragmentation) | — |
| 03 | Scroll (progress framework) | Nav appears |
| 04 | Scroll (relaxed) | — |
| 05 | Scroll + Hover (explore products) | — |
| 06 | Scroll (rise through industries) | — |
| 07 | Scroll (slow, contemplative) | — |
| 08 | Click (CTA, nav) | Scroll ends |

### Interaction Principles

- **Scroll is the primary narrative controller.** The visitor controls pace. SVARA controls sequence.
- **Mouse is the secondary explorer.** Hover reveals. Move influences. Click commits.
- **No interaction fights the visitor.** Every interaction responds within 200ms.
- **No interaction demands precision.** Hit targets are minimum 44x44px.
- **No interaction is required.** The narrative plays at scroll. The visitor never needs to do anything except scroll.

## 09 — Accessibility

- `prefers-reduced-motion: reduce` disables all non-essential animation
- Essential scene content is in DOM (not canvas) for screen readers
- Canvas world is `aria-hidden="true"`
- All scene text is readable at 200% zoom
- Skip-to-content link available from scene 01
- Scene indicator visible (progress bar or dots)
- Keyboard: Space/PageDown advances one scene

**If the visitor remembers one thing from each scene, they remember the category.**

Scene 01 → "Enterprise Intelligence Infrastructure is a category."
Scene 02 → "Data fragmentation is the problem."

Scene 04 → "SVARA is the infrastructure."
Scene 05 → "SVARA has products."

The visitor does not need to remember details. They need to remember the category exists, the problem is real, the framework is clear, and SVARA is the answer.
