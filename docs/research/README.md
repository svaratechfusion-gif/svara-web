# RESEARCH LIBRARY

## Phase -1. Before Book 1. Evidence, not imagination.

Every decision in SVARA OS is supported by research. No opinions. No guesses. Every claim has a source. Every design choice has a reference.

---

## How to use this library

1. Before making a decision, check if research exists for this topic
2. If research exists, cite it in the decision
3. If research does not exist, create it before making the decision
4. Every research entry includes: source, observation, decision, implementation

---

## Research workflow

```
Identify question
    ↓
Search existing research
    ↓
If found → reference it
    ↓
If not found → conduct research
    ↓
Document: source → observation → decision → implementation
    ↓
Add to library
```

---

## Research entry template

```yaml
Topic: Scroll Storytelling
Source: Apple Vision Pro
Observation: Scroll moves narrative, not page
Decision: Adopt
Reason: Creates continuity
Implementation: Master Timeline scrubbed by scroll progress
References: https://...
```

## The rule

**Every decision without a research reference is an opinion. Opinions do not ship.**
