# Design References

## Product Thinking

| Reference | Why | Key Takeaway |
|-----------|-----|-------------|
| **Apple** | Product launches as category creation | Lead with the problem, reveal the solution, show the evidence |
| **Stripe** | Enterprise clarity without enterprise dullness | Technical depth can be beautiful. Clear writing is a feature |
| **Linear** | Developer tools as craft | Every pixel serves function. Remove anything that doesn't help the user |
| **NVIDIA** | Complex technology, simple explanation | GTC keynotes teach the category before selling the product |

## Motion

| Reference | Why | Key Takeaway |
|-----------|-----|-------------|
| **Active Theory** | Scroll-driven 3D narratives | The browser is a 3D canvas. Scroll is the controller |
| **Resn** | Experimental web experiences | Break conventions, but always serve the message |
| **Dogstudio** | Emotional motion design | Motion creates feeling before understanding |

## Information Design

| Reference | Why | Key Takeaway |
|-----------|-----|-------------|
| **Bloomberg** | Data as narrative | Visualizations that tell stories, not just display numbers |
| **Palantir** | Enterprise UI as product | Complex systems can have clear interfaces. The key is information architecture |
| **IBM** | Design systems at scale | Consistency builds trust. A design system is a promise |
| **Microsoft** | Enterprise design language | Fluent Design System proves that enterprise products can be beautiful |

## Enterprise UX

| Reference | Why | Key Takeaway |
|-----------|-----|-------------|
| **Vercel** | Developer experience as brand | The product experience is the marketing |
| **Figma** | Collaborative design at scale | Design for teams, not individuals |
| **Notion** | Information complexity made simple | A blank page can be powerful. Too many options is not |

## Data Visualization

| Reference | Why | Key Takeaway |
|-----------|-----|-------------|
| **Refik Anadol** | Data as art | Machine learning creates beauty. Data has a soul |
| **Observable** | Interactive data narratives | Let the user explore. Don't just show |
| **Highcharts** | Enterprise data visualization | Clarity over creativity for business data |
