# Lighting Language

**Business:** Lighting intensity reinforces the emotional arc.
**User:** Feel the emotional state through ambient light.
**Owner:** `LightingLayer` (lib/experience/)
**Acceptance:** Collapse is measurably darker than Birth (5% vs 10%). Reconnect is peak (80%).

---

## Intensity Table

| Scene | Intensity | Notes |
|-------|-----------|-------|
| 01 — Birth | 10% | Baseline |
| 02 — Emergence | 25% | Growing |
| 03 — Intelligence | 45% | Core formation |
| 04 — Collapse | 5% | Darkest point. Darker than Birth. |
| 05 — Reconnect | 80% | Peak. Brightest point. |
| 06 — Products | 65% | Settled confidence |
| 07 — Industries | 50% | Warm landscape |
| 08 — Scale | 40% | Wide, cool |
| 09 — Invitation | 30% | Resolve |

## Transition

- Smooth GSAP tween between intensities
- Duration: 2s per transition
- Color temperature shifts subtly: warm during Reconnect, cool during Collapse
