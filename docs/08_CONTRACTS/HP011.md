# HP-011: IntelligenceWorld — Persistent Canvas

**Files:** `IntelligenceWorld.vue`, `WorldAtmosphere.vue`, `ParticleEngine.ts`, `CameraController.ts`

**Creative Intent:** One world, nine scenes. The canvas persists across the page.
**Business Intent:** The 3D world feels alive and continuous.
**Technical Intent:** Single Three.js scene and renderer. Camera managed by `CameraController`. Particles managed by `ParticleEngine`.

**Dependencies:** `Three.js`, `TresJS`, `ParticleEngine`, `CameraController`

## Acceptance Criteria

- ✓ Single canvas element for entire experience
- ✓ No canvas flicker during scroll
- ✓ World disposes on route change
- ✓ `<ClientOnly>` wraps the canvas
- ✓ Particles capped: 50k desktop, 10k mobile
