# HP-011: IntelligenceWorld — Persistent Canvas

**Purpose:** Single Three.js scene and renderer that persists across all 9 homepage scenes. Never remounts during scroll.
**Owner:** OpenCode
**Dependencies:** Three.js v0.185.1, TresJS, ParticleEngine, CameraController
**Inputs:** Scene color palette (from LightingLayer), device pixel ratio, viewport dimensions
**Outputs:** Single WebGL canvas, single render loop, scene disposal on route change
**Files:** IntelligenceWorld.vue, WorldAtmosphere.vue, ParticleEngine.ts, CameraController.ts
**Acceptance:** Single canvas element for entire experience. No canvas flicker during scroll. World disposes on route change. <ClientOnly> wraps the canvas. Particles capped: 50k desktop, 10k mobile.
**Performance Budget:** ≤16ms total frame budget (8ms Three.js + 8ms particles + 0ms overhead). ≤1 canvas element. Zero canvas re-creation during scroll.
**QA Checklist:**
- [ ] Exactly one <canvas> element on the homepage
- [ ] No canvas flicker or white flash during scene transitions
- [ ] <ClientOnly> prevents SSR of canvas
- [ ] Scene.dispose() called on route change (beforeNavigate)
- [ ] Desktop: ≤50,000 particles. Mobile: ≤10,000 particles.
- [ ] Renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
- [ ] No canvas on platform, products, or subpages
