# HP-010: Master Timeline & Scroll Infrastructure

**Purpose:** Drive the entire 9-scene experience through a single scroll-controlled timeline. One rAF pump. Zero drift.
**Owner:** OpenCode
**Dependencies:** GSAP 3.15.0, Lenis 1.3.25
**Inputs:** Scroll position (0–100%), Lenis velocity, device pixel ratio
**Outputs:** Single paused GSAP timeline scrubbed by ScrollTrigger, Lenis driven by gsap.ticker
**Files:** MasterTimeline.ts, ScrollController.ts, MotionDirector.ts, pacing.ts, app.vue
**Acceptance:** Single rAF pump: gsap.ticker calls lenis.raf(). Single ScrollTrigger via ScrollController. Single timeline via MasterTimeline. gsap.ticker.lagSmoothing(0) applied. Reduced motion: Lenis lerp = 1, no animations. No requestAnimationFrame outside gsap.ticker.
**Performance Budget:** ≤2ms per frame for scroll infrastructure. Zero memory leaks on route change.
**QA Checklist:**
- [ ] gsap.ticker is the only rAF driver
- [ ] lenis.raf() called from gsap.ticker, not window rAF
- [ ] MasterTimeline is a single gsap.timeline({ paused: true })
- [ ] ScrollController creates exactly one ScrollTrigger
- [ ] gsap.ticker.lagSmoothing(0) is set
- [ ] Reduced motion: lerp = 1, all tweens disabled
- [ ] No window.requestAnimationFrame calls anywhere in experience code
- [ ] Timeline disposes on route change (ScrollTrigger.getAll().forEach(st => st.kill()))
