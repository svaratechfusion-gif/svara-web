# HP-012: AppHeader — Progressive Reveal

**Files:** `AppHeader.vue`, `app.vue`

**Creative Intent:** Navigation should feel earned, not expected.
**Business Intent:** Full focus on the story for the first 48% of scroll.
**Technical Intent:** Homepage nav opacity 0 until scroll > 48vh. Other pages: visible from load.

**Dependencies:** None

## Acceptance Criteria

- ✓ Nav hidden on `/` for first 48% of viewport height
- ✓ Nav visible on all other pages from page load
- ✓ Smooth opacity + translateY transition (500ms)
- ✓ Nav items use `NuxtLink`
- ✓ Reduced motion: opacity only, no transform
