# HP-012: AppHeader — Progressive Reveal

**Purpose:** Navigation stays hidden during the first 48% of the homepage story, then earns its reveal. On subpages, always visible.
**Owner:** OpenCode
**Dependencies:** None
**Inputs:** Route path, scroll position (percentage of viewport height)
**Outputs:** Nav opacity (0 → 1), translateY transform, visible/hidden state
**Files:** AppHeader.vue, app.vue
**Acceptance:** Nav hidden on / for first 48% of viewport height. Nav visible on all other pages from page load. Smooth opacity + translateY transition (500ms). Nav items use NuxtLink. Reduced motion: opacity only, no transform.
**Performance Budget:** ≤0ms (CSS transitions, no JS animation). Zero layout shift on reveal.
**QA Checklist:**
- [ ] Homepage: nav opacity = 0 when scroll < 48vh
- [ ] Homepage: nav opacity transitions to 1 when scroll > 48vh
- [ ] Platform page: nav visible on load (no hiding)
- [ ] Products page: nav visible on load
- [ ] Transition: 500ms, ease-out
- [ ] Nav items are NuxtLink components
- [ ] Reduced motion: opacity only, translateY removed
- [ ] Nav has glass blur (22px) when scroll > 0 on any page
