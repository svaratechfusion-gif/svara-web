# HP-013: PageLoader — Cold Boot Sequence

**Purpose:** Transform cold load into an intentional boot experience. No loading spinner. No progress bar.
**Owner:** OpenCode
**Dependencies:** None
**Inputs:** Page load event (cold vs client nav), usePageReveal composable state
**Outputs:** PageLoader visibility, scale transform (0.97 → 1), transformDone flag
**Files:** PageLoader.vue, app.vue, usePageReveal.ts
**Acceptance:** PageLoader visible on cold load. PageLoader skipped on client-side navigation. Scale transition: 0.97 → 1 over 700ms. transformDone removes transform after transition. Reduced motion: no scale animation.
**Performance Budget:** ≤2ms script cost. Zero layout shift. Zero CLS impact.
**QA Checklist:**
- [ ] Cold load: PageLoader renders, then fades out
- [ ] Client nav: PageLoader does not render (no flash)
- [ ] app.vue scale: 0.97 → 1 over 700ms on cold load
- [ ] transformDone removes transform styles after transition
- [ ] Reduced motion: scale stays at 1, no transform
- [ ] No loading spinner, skeleton, or progress bar
