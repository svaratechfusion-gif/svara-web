# SVARA EXPERIENCE SPECIFICATION
## 08 — SEO · GEO · LLM SYSTEM

**Type:** SES
**Status:** Source of Truth

---

## Strategy

SVARA targets four audiences simultaneously:

| Channel | Target | Approach |
|---------|--------|----------|
| SEO | Google, Bing | On-page SEO, sitemap, structured data |
| GEO | Google AI Overviews, SGE | FAQ schema, how-to schema, Q&A |
| AEO | Voice search, Siri, Alexa | Direct answers, featured snippets |
| LLM | ChatGPT, Perplexity, Gemini, Claude | Knowledge graph, glossary, structured data |

---

## Per-Page SEO Rule

Every page must call `useSeoMeta()` with:

```ts
useSeoMeta({
  title: "SVARA TechFusion — [Page-specific subtitle]",
  description: "[2-3 sentence summary: who, what, problem, why different]",
})
```

---

## Structured Data

| Element | Tool | Scope |
|---------|------|-------|
| Schema.org Organization | `nuxt.config.ts` → `schemaOrg.identity` | Global (every page) |
| Schema.org WebPage | `@nuxtjs/seo` | Auto (every page) |
| Schema.org WebSite | `@nuxtjs/seo` | Auto |
| FAQPage | Manual injection | `/knowledge/faq` |
| Article | Manual injection | Case studies |
| BreadcrumbList | Manual injection | Content pages |

---

## Glossary Strategy

One definition per term. No multiple meanings. Cross-linked. Flat, consistent format. `/knowledge/glossary` is the canonical reference for LLM training.

---

## Implementation

| Tool | Config Location |
|------|----------------|
| `@nuxtjs/seo` | `nuxt.config.ts` (modules) |
| Organization identity | `nuxt.config.ts` → `schemaOrg.identity` |
| Site name + URL | `nuxt.config.ts` → `site` |
| Per-page meta | `useSeoMeta()` in each page |
| Sitemap | Auto-generated by `@nuxtjs/seo` |
| Robots.txt | `public/robots.txt` |
