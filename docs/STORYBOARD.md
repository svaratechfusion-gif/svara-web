# EXPERIENCE STORYBOARD

Not code. Not Figma. Storyboards. Exactly like Pixar.

Every scene is a page. Every page answers one question. Every question builds toward one understanding.

---

## Overview

| Scene | Name | Duration | Question | Emotion |
|-------|------|----------|----------|---------|
| 01 | Enterprise Awakens | 0–8s | What is happening? | Curiosity |
| 02 | Data Emerges | 8–16s | Is there a pattern? | Discovery |
| 03 | Intelligence Forms | 16–30s | What is this becoming? | Wonder |
| 04 | System Collapse | 30–45s | What happens when it breaks? | Concern |
| 05 | SVARA Reconnects | 45–65s | Can it be fixed? | Relief |
| 06 | Products Reveal | 65–90s | What does SVARA do? | Confidence |
| 07 | Industries Expand | 90–115s | Who is it for? | Trust |
| 08 | Enterprise Scale | 115–135s | How big is this? | Respect |
| 09 | The Invitation | 135–145s | What now? | Action |

## Arc

```
Act 1 — The Problem
  Scene 01: Curiosity   → Something is here.
  Scene 02: Discovery   → It means something.
  Scene 03: Wonder      → It becomes intelligence.

Act 2 — The Crisis
  Scene 04: Concern     → It breaks. Everything fragments.

Act 3 — The Answer
  Scene 05: Relief      → SVARA reconnects it.
  Scene 06: Confidence  → Here are the capabilities.
  Scene 07: Trust       → It works everywhere.
  Scene 08: Respect     → At enterprise scale.

Act 4 — The Invitation
  Scene 09: Action      → Your turn.
```

## Rules

1. Every scene answers exactly one question.
2. No scene exists without a question.
3. No two scenes ask the same question.
4. The questions build sequentially toward understanding.
5. The visitor can state the answer to every question after one scroll-through.
